# Product

## Platform
web

## Stack
Existing React 19, Vite and Tailwind 4 website; Rust/Tauri desktop app and Go CLI.

## Product Purpose
Nightfall brings free desktop snow and winter decorations to macOS and Linux. The website lets visitors understand the experience and install it.

## Capabilities and Constraints
Snowfall, accumulation, decorations, snowballs and Santa cleanup. macOS and Arch/Hyprland installation actions and real product facts must remain. No invented endorsements or performance claims.

## Brand Commitments
User approved a detailed softly illustrated alpine landscape, snowy mountains, pines, snowman and warm Christmas lights. Local-time morning, afternoon, evening and night themes with manual override. Expressive headline typography and readable controls. Build step by step with multiple commits per stage.

## Evidence on Hand
Existing desktop screenshot at website/public/nightfall-desktop.webp; native UI under desktop/ui; installation commands in website/src/landing.jsx. User supplied a motion reference recording and Letterbloom entrance brief.

## Product Principles
Demonstrate the actual snow experience. Keep installation clear. Preserve readable controls as snow gathers. Respect reduced motion and mobile constraints.
